# Governance

## Overview

CareerPilot is an independent, community-friendly open-source project. It's kept intentionally small and focused, with a clear path for anyone to contribute and take on more responsibility over time.

The goal is a project that's easy to contribute to, transparent in how decisions are made, and stable for the people who rely on it.

## Decision Making

- **Architecture decisions** (data contract, scoring system, core pipeline) — decided by the project maintainers, with discussion in issues
- **New features** — open an issue to align on direction before submitting a PR
- **Bug fixes** — can be submitted directly with a clear description
- **Documentation and translations** — welcome from anyone, low barrier

## Contributor Ladder

Anyone can grow their role in the project. Roles are earned through sustained, quality contributions — not requested or assigned.

### Participant

**Everyone starts here.**

- Follow the [Code of Conduct](CODE_OF_CONDUCT.md)
- Open issues, comment on PRs, help others
- Submit bug reports with reproduction steps

### Contributor

**Earned after 2+ merged PRs.**

- Credited in release notes when their contributions ship
- Input is weighted more heavily in issue discussions
- Can be tagged for review on PRs in their area of expertise

### Reviewer

**Earned after several quality PRs merged + a track record of helpful code reviews.**

- Can approve PRs
- Invited to architectural discussions before major changes

### Maintainer

**Earned after sustained contribution + demonstrated alignment with project values.**

- Can merge PRs and cut releases
- Participates in governance decisions

## How to Level Up

You don't apply for roles. They emerge naturally:

1. **Start contributing** — fix a bug, translate a mode, improve docs
2. **Be consistent** — one quality PR beats ten rushed ones
3. **Help others** — answer questions, review PRs, triage issues
4. **Understand the project** — read the architecture docs and the data contract

## Values

- **Quality over quantity** — a few great features beat many mediocre ones
- **User files are sacred** — the data contract is non-negotiable
- **Human in the loop** — the system recommends, the human decides
- **Respect everyone's time** — maintainers, contributors, and users alike
