How it works

Scan. Score. Apply.

Three loops that run on your machine. No SaaS, no subscription, no data leaving your computer.

01

Scan tracked companies

Hits 45+ Greenhouse, Lever, and Ashby boards directly. Zero LLM tokens. New roles land in your inbox sorted by freshness.

02

Score against your CV

Runs the real evaluation — blocks A–F, posting legitimacy check, fit narrative — grounded in your actual CV and profile. Keywords reformulated, never fabricated.

03

Apply with a tailored CV

Generates an ATS-optimized PDF for each application. Tracks status from Evaluated → Interview → Offer. You review before anything is sent.

Why it's different

Built to be trusted.

Not another SaaS scraper. Every decision is grounded in your real CV, runs on your machine, and waits for your sign-off.

🔒

Local-first, always

Your CV, your matches, your reports — every file stays on your disk. No account, no telemetry, no data leaving your computer. The dashboard reads and writes the same files the CLI uses.

🎯

Grounded, never fabricated

Scoring pulls from your actual CV and profile. Keywords get reformulated to match a posting, never invented. If a fact isn't in your source files, it never makes it into a CV.

⚡

Zero-token scanning

Hits Greenhouse, Lever, and Ashby boards directly. No LLM cost to find fresh roles.

🛡️

Legitimacy checks

Flags ghost jobs and reposts before you waste effort, so you only apply to real openings.

✋

You stay in control

Drafts and prefills only. Nothing is submitted on your behalf — you review every application.

Windows Setup

Download or clone the repo, then run the installer once to create a desktop shortcut:

git clone https://github.com/Kunalchandra007/CareerPilot
cd CareerPilot
powershell -ExecutionPolicy Bypass -File install-shortcut.ps1

Then double-click CareerPilot on your Desktop.

macOS / Linux Setup

Clone the repo and run the web app directly:

git clone https://github.com/Kunalchandra007/CareerPilot
cd CareerPilot/web
npm ci && npm run build && npm start

Then open http://localhost:3000 in your browser.

API Key Mode

No CLI to install. After starting CareerPilot:

  1. Open Config in the sidebar
  2. Select "Paste an AI key"
  3. Enter your Anthropic API key (sk-ant-…)
  4. Click Save config

Get a key at console.anthropic.com →
